# Create Disease

## Pre-Condition

- The Disease Category to be selected in the **Category** field already exists, if the
  disease needs to be classified.

## Flow

1. Open the **Health > Configuration > Diseases** menu.
2. Click the **New** button.
3. Fill in the required fields:
   - **Name**: Enter the name of the disease.
   - **Code**: Enter a unique code identifying this disease. Enter **/** to generate the
     code automatically later using the **Generate Code** button.
   - **Category**: Select the Disease Category classifying this disease. Leave empty if
     the disease does not belong to any category.
4. Click **Save**.
5. Click the **Diseases** breadcrumb link to return to the list.

## Post-Condition

- A new Disease record is created and active.
- The new Disease appears in the Diseases list view.
