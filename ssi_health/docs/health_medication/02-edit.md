# Edit Medication

> **Module:** `ssi_health`\
> **Model:** `health.medication`\
> **Menu:** Health > Configuration > Medications\
> **Actor:** user in group _Medication_\
> **Requires:** `01-create`

## Pre-Condition

- **Access:** user in group _Medication_.

## Flow

1. Open the **Health > Configuration > Medications** menu.
2. Find and open the Medication record to edit.
3. Click the **Edit** button.
4. Change the required fields (Name, Code).
5. Click **Save**.

## Post-Condition

- The Medication record is updated with the new values.
