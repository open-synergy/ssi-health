# Edit Health Provider Role

> **Module:** `ssi_health`\
> **Model:** `health.provider_role`\
> **Menu:** Health > Configuration > Provider Roles\
> **Actor:** user in group _Health Provider Role_\
> **Requires:** `01-create`

## Pre-Condition

- **Access:** user in group _Health Provider Role_.

## Flow

1. Open the **Health > Configuration > Provider Roles** menu.
2. Find and open the Health Provider Role record to edit.
3. Click the **Edit** button.
4. Change the required fields (Name, Code, Provider Type).
5. Click **Save**.

## Post-Condition

- The Health Provider Role record is updated with the new values.
