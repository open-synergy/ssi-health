# Edit Allergen

## Pre-Condition

- None.

## Flow

1. Open the **Health > Configuration > Allergens** menu.
2. Find and open the Allergen record to edit.
3. Click the **Edit** button.
4. Change the required fields (Name, Code, Category).
5. Click **Save**.

## Post-Condition

- The Allergen record is updated with the new values.
