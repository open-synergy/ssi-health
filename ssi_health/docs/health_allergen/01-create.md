# Create Allergen

## Pre-Condition

- The Allergen Category to be selected in the **Category** field already exists, if the
  allergen needs to be classified.

## Flow

1. Open the **Health > Configuration > Allergens** menu.
2. Click the **New** button.
3. Fill in the required fields:
   - **Name**: Enter the name of the allergen.
   - **Code**: Enter a unique code identifying this allergen. Enter **/** to generate
     the code automatically later using the **Generate Code** button.
   - **Category**: Select the Allergen Category classifying this allergen. Leave empty
     if the allergen does not belong to any category.
4. Click **Save**.
5. Click the **Allergens** breadcrumb link to return to the list.

## Post-Condition

- A new Allergen record is created and active.
- The new Allergen appears in the Allergens list view.
