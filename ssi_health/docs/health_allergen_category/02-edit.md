# Edit Allergen Category

## Pre-Condition

- None.

## Flow

1. Open the **Health > Configuration > Allergen Categories** menu.
2. Find and open the Allergen Category record to edit.
3. Click the **Edit** button.
4. Change the required fields (Name, Code).
5. Click **Save**.

## Post-Condition

- The Allergen Category record is updated with the new values.
