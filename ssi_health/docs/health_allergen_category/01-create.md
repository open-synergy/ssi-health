# Create Allergen Category

## Pre-Condition

- None.

## Flow

1. Open the **Health > Configuration > Allergen Categories** menu.
2. Click the **New** button.
3. Fill in the required fields:
   - **Name**: Enter the name of the allergen category.
   - **Code**: Enter a unique code identifying this allergen category. Enter **/** to
     generate the code automatically later using the **Generate Code** button.
4. Click **Save**.
5. Click the **Allergen Categories** breadcrumb link to return to the list.

## Post-Condition

- A new Allergen Category record is created and active.
- The new Allergen Category appears in the Allergen Categories list view.
- The new Allergen Category becomes selectable as a **Category** for Allergen records.
