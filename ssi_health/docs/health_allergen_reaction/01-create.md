# Create Allergen Reaction

> **Module:** `ssi_health`\
> **Model:** `health.allergen_reaction`\
> **Menu:** Health > Configuration > Allergen Reactions\
> **Actor:** user in group _Allergen Reaction_

## Pre-Condition

- **Access:** user in group _Allergen Reaction_.

## Flow

1. Open the **Health > Configuration > Allergen Reactions** menu.
2. Click the **New** button. **(14.0: "Create")**
3. Fill in the required fields:
   - **Name**: Enter the name of the allergen reaction.
   - **Code**: Enter a unique code identifying this allergen reaction. Enter **/** to
     generate the code automatically later using the **Generate Code** button.
4. Click **Save**.
5. Click the **Allergen Reactions** breadcrumb link to return to the list.

## Post-Condition

- A new Allergen Reaction record is created and active.
- The new Allergen Reaction appears in the Allergen Reactions list view.
