# Edit Allergen Reaction

> **Module:** `ssi_health`\
> **Model:** `health.allergen_reaction`\
> **Menu:** Health > Configuration > Allergen Reactions\
> **Actor:** user in group _Allergen Reaction_\
> **Requires:** `01-create`

## Pre-Condition

- **Access:** user in group _Allergen Reaction_.

## Flow

1. Open the **Health > Configuration > Allergen Reactions** menu.
2. Find and open the Allergen Reaction record to edit.
3. Click the **Edit** button.
4. Change the required fields (Name, Code).
5. Click **Save**.

## Post-Condition

- The Allergen Reaction record is updated with the new values.
